Instruction: 모듈 2 (시뮬레이션 / 자금설계) — 기능 1, 기능 2(1) + 저장정책 최종
1. 사전 데이터 — 지역 시세 CSV
   컬럼 구성: 지역, 평균보증금, 평균월세
   애플리케이션 로딩 시점에 파싱해 조회 가능한 형태로 적재
2. 기능 1. 자취 목표 설정
   2-1. 사용자 입력
   필드	설명
   region	희망 지역 (서울 25개구 중 선택)
   housingType	계약 방식 (JEONSE / WOLSE) => enum으로 설정
   2-2. 보증금·월세 산출
   전세(JEONSE): 보증금 = CSV 해당 지역 평균보증금, 월세 = 0
   월세(WOLSE): 보증금 = 1,000만원(고정값), 월세 = CSV 해당 지역 평균월세
   2-3. 중개수수료 계산

거래금액

거래금액 = 보증금 + (월세 × 100)
단, 거래금액 < 5,000만원이면:
거래금액 = 보증금 + (월세 × 70)

요율표

거래금액 구간	상한요율	한도액
5,000만원 미만	0.5%	20만원
5,000만원 ~ 1억원 미만	0.4%	30만원
중개수수료 = min(거래금액 × 상한요율, 한도액)

거래금액이 1억원 이상인 지역이 CSV에 존재하면 요율표 미정의 상태이므로 예외 처리 필요 — 발견 시 별도 보고.

2-4. 필요금액 (최종)
필요금액 = 보증금 + (월세 × 2) + 중개수수료
3. 기능 2(1). AI 자취 시작 가능 시점 예측 — 기본 연산
   3-1. 현재 보유금액
   현재 보유금액 = (예금 + 적금 + 투자자산) - 남은상환금액

※ 사용자의 MyDataSnapshot 자체가 존재하지 않는 경우(마이데이터 미연동), 모든 자산 항목을 0으로 간주하여 현재 보유금액 = 0으로 계산한다.

3-2. 월 저축가능금액
월 저축가능금액 = 월평균소득 - 월소비총합
(월소비총합 = 식비 + 문화·취미 + 쇼핑 + 기타소비 + 고정비용 합계)

예외 처리 (아래 중 하나라도 해당 시 대체값 적용)

계산 결과가 음수
MyDataSnapshot이 없거나 null
위 조건 해당 시:
월 저축가능금액 = 월평균소득 × 0.2
3-3. 소요 개월 / 예측 시점
현재 보유금액 >= 필요금액:
소요개월 = 0
그 외:
소요개월 = ceil((필요금액 - 현재 보유금액) / 월 저축가능금액)

예측 자취 시작 가능 시점 = 현재 날짜 + 소요개월
4. 저장정책 (최종 확정)
   비교 로직 없음. 이력(다건) 저장 없음.
   SimulationResult는 사용자당 최신 결과 1건만 유지한다 (MyDataSnapshot과 동일한 upsert 패턴).
   재계산 시 기존 레코드를 덮어쓴다 (UPDATE), 별도 이력 테이블 생성하지 않는다.
   테이블 구조
   SimulationResult
- userId (PK, FK → User)         ← 1:1 관계, User당 1행
- region
- housingType
- deposit
- monthlyRent
- brokerageFee
- requiredAmount                  ← 기능1 최종값
- currentAsset
- monthlySavingCapacity
- isFallbackApplied               ← 대체값(소득×20%) 적용 여부
- estimatedMonths
- predictedStartDate
- updatedAt
5. 공통 적용 사항
   오류 응답: auth 모듈에서 정의한 통일 양식(success, errorCode, message, timestamp) 그대로 사용
   CSV에 없는 지역 요청 시 별도 에러코드(SIMULATION_001) 처리
   모든 금액 단위는 원(KRW), 정수(Long)로 통일

확인/전제 사항 (큰 문제 없으면 아래 전제로 진행)
   자산 스냅샷 전체 부재 시 처리: 명시적 지침이 없어, 마이데이터 미연동 사용자는 현재 보유금액 = 0으로 전제했습니다. (저축가능금액의 fallback 규칙과는 별개 로직입니다.)
   SimulationResult와 MyDataSnapshot의 관계: 계산 시점의 소득/자산 값을 스냅샷 형태로 복사 저장하지 않고, 매번 최신 MyDataSnapshot을 조회해서 재계산하는 구조로 전제했습니다.
   거래금액 1억원 이상 구간 :  상한요율 1천분의 3, 한도액 없음으로 계산
